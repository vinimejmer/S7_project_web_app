# S7_proyect_web_app
Sprint 7 proyect. Web App

El aplicativo utiliza una base de datos de automóviles en USA
Qué hace?
    Ofrece al usuario dos opciones: 
        1: Generar un histograma de la distribución de anuncios de la venta de coches
        2: Genera un gráfico de dispersión entre odómetro y el precio de los autos
